# To-Do List – Frontend (React + Vite)

Sign up, log in and manage your own to-do list from a protected dashboard.

## Run locally
1. `npm install`
2. Copy `.env.example` to `.env` (set `VITE_API_URL` to the backend address)
3. `npm run dev` (http://localhost:5173)

## Deploy on Vercel
Set the environment variable `VITE_API_URL` to `https://YOUR-BACKEND.vercel.app/api`.
